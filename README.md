# eRead Web

免费的网页阅读器。正文使用主页面普通 DOM，支持浏览器查词插件；应用可由 Edge / Chrome 安装到桌面。

## 维护与接手

日后开启新对话，请先提供仓库链接并让助手阅读 [维护与交接手册](HANDOVER.md)。手册包含本机源码位置、发布步骤、检查范围、数据限制和待讨论方案。当前仓库主要是网页发布文件与查词后台，尚未保存完整前端源码；不能仅靠本仓库重建整个阅读器。

新名字与图标尚未选定，见 [品牌候选](BRANDING.md)。云同步与自动文件备份仍是计划，尚未启用。

## GitHub Pages 上线

这个目录只包含网页程序和部署配置，没有用户书籍、笔记、背景图片或账号凭据。

1. 创建一个公开 GitHub 仓库，默认分支为 `main`。
2. 将本目录的 `public`、`.github` 和本 README 上传到仓库根目录，保留目录结构。
3. 打开仓库 Settings → Pages → Source，选择 **GitHub Actions**。
4. 在 Actions 页面运行 **Deploy eRead Web**。部署成功后，在 Settings → Pages 获取实际网址。

免费 GitHub Pages 使用公开仓库。上传后的网页代码会公开；阅读数据仍保存在各访问者自己的浏览器，程序不会上传书籍。

## 使用

- 导入 EPUB、TXT、Markdown 或 DOCX；书架、收藏、阅读位置、分页、目录、书签、笔记、手动生词本、搜索和排版设置保存在浏览器。
- 可以结合第三方浏览器插件辅助学习，在浏览器扩展管理中允许插件访问网站。
- 通过 Edge / Chrome 菜单安装 eRead。请使用安装了插件的同一浏览器配置。
- 首次在线打开、离线资源缓存完成后，可离线打开和阅读已导入的书籍。插件本身的查词可能仍需要网络。
- 朗读使用免费 Web Speech。具体声音和离线能力取决于浏览器与系统。
- 在设置中导出完整备份；可导入网页备份或桌面版完整 JSON 备份。导入前会自动下载当前数据备份。
- 内置查词默认关闭，可在设置中启用必应中文和英文释义，收藏时保留释义、原文与来源链接。其他读者无需注册后台账号。eRead 生词本与第三方插件生词本分别保存。
- 朗读提供当前阅读位置、本章开头和选区起读，以及暂停、继续、停止、句子切换、语速、跟随正文。第一句显示柔和高亮，正文始终保持普通 DOM 文本。
- 直线和波浪线与文字保持间隔，不影响选择或插件识别；章节之间的阅读位置独立保存，再次进入章节时恢复。
- 「我的笔记」在窄窗口顶部也可访问，支持筛选、编辑、原文定位、多选删除和 HTML、TXT、Markdown、CSV 导出。书籍卡片的「管理」按钮可以收藏或整理书籍。
- 更新可用时，点击状态栏「更新版本」。如果仍显示旧界面，可在浏览器按 Ctrl + Shift + R 强制刷新。
- 更换域名、浏览器或清除网站数据后，需要重新导入备份。云同步尚未启用。

## 验证范围

自动检查覆盖 DOM 文本、插件包裹文本后的选区和划线、四种书籍格式、本地持久化、网页与桌面备份、离线启动、五种窗口宽度下的布局、笔记操作与导出、书签、章节位置恢复、查词开关与生词收藏，以及第一句、实体、行内格式和 emoji 的朗读高亮。朗读通过浏览器回调验证控制流程，实际声音取决于系统和浏览器。

隔离 Edge 浏览器已通过公网 Cloudflare 后台查询必应词条，获得中英文释义。安装条件检查无错误，第三方插件的划词入口通过隔离配置检查；安装后的独立窗口行为仍需要在实际浏览器配置中验收。

## 查词后台

当前默认服务已连接 Cloudflare Workers。只有网站维护者需要账号，读者无需账号；后台只接收查询词语，书籍与个人笔记始终保存在浏览器。配置与维护方法见 [后台说明](dictionary-worker/README.md)。免费英文补充服务尚未开放，英文释义直接取自必应，部分词条可能没有英文释义。

云服务免费额度见 [Cloudflare 官方说明](https://developers.cloudflare.com/workers/platform/pricing/)。本项目不启用付费服务，额度用尽时查词可能暂不可用；本地阅读和笔记仍可使用。
