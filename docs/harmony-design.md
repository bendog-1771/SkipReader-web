# 跃境：背景中的练习与完整的风

本轮使用 frontend-design、emil-design-eng、vercel-react-best-practices 的设计与性能原则。

色彩基准：深海 #102237、云白 #e9f0f3、星金 #d7bd97、雾蓝 #adc6cd、墨蓝 #233c52。普通界面沿用应用主题；专注练习使用星轨的浅色文字，保持对比。Georgia/宋体负责摘录，Segoe UI/微软雅黑负责操作。

```
普通练习： [释义 / 原文 / 答案]           (星轨)
专注练习：        返回    模式    退出专注
                 释义与原文
                   答案
                 进度 / 选词
       星轨移动到右上，练习直接留在同一片星空中
风：           完整摘录，紧密换行
                       另一段完整摘录
```

| Before | After | Why |
| --- | --- | --- |
| 固定 72 字拆开，分散到不同位置 | 完整来源独立成组，长摘录在同一位置续页 | 保留句意和阅读顺序 |
| 专注练习有实体卡片和模糊蒙版 | 透明居中内容、清晰星轨、柔和局部暗影 | 让练习属于背景本身 |
| 恒星完成长按后突然换位置 | 同一个渲染器平滑移动、辉光延续 | 长按和进入是同一个动作 |
| 音频柱无限拉长 | 限幅、平滑、内圈短弧节律 | 不穿过单词和外圈 |
| 云噪声像液体纹理 | CC0 实拍天空与同源倒影，离线程序回退 | 用真实云形，避免昂贵体积云 |

特异性复核：不新增一套通用卡片界面。完整摘录是风景的主体；星轨留在练习旁边；云资源只用于真实海面光景。装饰服从可读性，不替代用户书籍与生词。
