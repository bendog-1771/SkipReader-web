# SkipReader · 一跃

免费网页阅读器：[打开网站](https://bendog-1771.github.io/eRead-web/)。原名 eRead Web。名称和图标已更新，网址、浏览器数据库标识和安装 ID 保持兼容，已有书库不需要迁移。

正文使用主页面普通 DOM，可结合第三方浏览器插件辅助学习。支持 EPUB、TXT、Markdown、DOCX，笔记、生词、书签、搜索、章节位置、排版和免费浏览器朗读，也可在 Edge / Chrome 安装到桌面。第三方插件在独立窗口中的行为由浏览器和插件决定。

## 跃境 · v0.5.0

v0.5.0 提供可关闭的文字风景、海的慢呼吸、书页留影和词语星轨，默认关闭。入口在书库「我的笔记」下方和阅读工具栏；关闭跃境恢复普通阅读，原主题和背景保留。详见 [跃境说明](YUJING.md)。正式网站继续使用原网址，既有书库与安装标识保持兼容。

背景跟随应用主题默认关闭；内置查词默认开启，已保存的个人选择保留。专注练习直接置于清晰星空中，不打开新页面。

光的时刻支持跟随电脑本地时间，已有手动选择保留；太阳／月亮与海面倒影方向一致。风中文字按长度完整停留 8–18 秒，切换书籍视图不重播。星轨频谱保持同心，鼓点会形成短促的光浪；各频带有独立冲击与自然回落。太阳有清楚可见的暖色圆盘、柔和边缘和云层遮光。

设置在跃境入口附近分为画面、文字、声音和性能。风中句子成组换行、原位续页，有完整阅读停留、接触拨动和临时选句；清瓶配合免费 CC0 实拍天空与倒影，悬浮显示点击指针。画质可选自动、节能、精致，阅读降帧、后台停绘，屏外照片暂停摆动。

「书页留影」将自己的书封排成夹在麻绳上的照片，轻轻随风摆动，点击直接打开原书，右键或三点继续管理；多本书正常分行滚动，搜索、收藏、书架与排序保留。云上书岛已弃用。

海面采用 Blender 自制的近处加密网格、非周期细浪与天空反射；三种玻璃漂流瓶有厚度、卷纸、木塞和系绳。漂流信仅在主页使用，阅读时隐藏并避免首次加载瓶子。新信十分钟后参与随机回信，信件只保存本机并进入完整备份。

星轨主页每次进入／返回会随机显示实际生词。悬浮提示已撤掉；侧栏「星轨练习」在书多时仍可进入，恒星仅左键长按进入、逐渐变亮；新增居中专注练习。候选池不限 48 个，每轮最多 48 个，可随机或自选。电脑媒体声音为直接入口，标签页／系统音频使用浏览器授权；本地音乐和试听无需共享。

本机目录已分开：`SkipReader-web` 是当前网页源码，`SkipReader-legacy` 保存旧 Windows 开发版，`SkipReader-art-lab` 是独立试玩入口。双击当前目录的「打开SkipReader网页版.bat」打开本地接入版；独立试玩地址为 http://localhost:5174/lab.html 。

## 数据保护怎么用

进入「设置 → 备份与日志」：

1. **自动文件备份**：选择电脑文件夹，第一次立即备份；之后在应用打开、有修改时按 15 分钟／1 小时／1 天备份。保留最近 3／7／14 份。浏览器可能要求重新授权文件夹，界面会显示成功时间和失败原因。不删除其他文件。
2. **可选云同步**：点击「创建云账号」，下载登录恢复卡，确认已妥善保存后开启。其他设备打开相同网站，导入恢复卡或粘贴登录码即可合并学习记录，不需要邮箱或 Cloudflare 账号。
3. **历史恢复**：已登录时打开「查看历史版本」，可恢复最近 10 个有笔记、生词等学习内容变动的历史版本。恢复后会同步到其他设备，恢复前的云端版本仍在历史内。

自动文件备份包含完整书籍、设置和学习记录，文件未加密，应保存在自己的安全文件夹。登录恢复卡仅包含账号钥匙，不能代替书籍备份。丢失恢复卡且清除已登录设备后无法找回云端记录；不要分享恢复卡或上传到公开仓库。

云同步只上传在浏览器中加密的笔记、生词、书签、生词本和位置，包含书籍关联元数据；整本书、封面、背景图片和设备设置不上传。在其他设备导入**同一份书籍文件**后即可重新关联原文。离线可以修改，联网后合并；不同记录一起保留，同一记录以较新修改为准。

本地文件夹权限主要由 Edge / Chrome 支持，其他浏览器可以手动「导出备份」。应用关闭时网页不能定时写文件，云同步也不会继续。清除浏览器数据不会删除已经写入电脑的备份和云端数据，但会清除本机书库和登录状态。恢复可导入完整备份，或使用恢复卡取回学习记录后重新导入书籍。

## 维护与接手

本仓库已保存可重建的**完整网页版源码**、依赖锁文件、自动检查和两个后台。进入 [维护与交接手册](HANDOVER.md) 查看 GitHub 基础、修改入口、发布、回退和新对话开场白。品牌设计见 [名称和图标](BRANDING.md)。旧 Windows 应用的安装和后台代码不属于此网页仓库。

本机预览需要 Node.js 24：

```powershell
npm ci --ignore-scripts
npm run typecheck:web
npm run test:sync
npm run test:dictionary
npm run build:web
npm run start:web
```

打开 http://localhost:5174/ 。浏览器端测试先运行 `npx playwright install chromium`，预览运行时再执行 `npm run test:web`。真实云服务检查为 `npm run test:protection`，会创建并删除测试账号，并受注册限流影响。

## 发布

GitHub Actions「Deploy SkipReader Web」在 main 更新后自动安装依赖、检查类型、检查加密合并和后台、从源码构建，再发布到 GitHub Pages。生成的 `web-site/public` 不提交。Settings → Pages → Source 为 GitHub Actions。修改源码后看 Actions 的绿色结果，不要直接编辑以前的压缩发布文件。

查词与同步后台独立部署。服务地址分别配置于 `web-site/dictionary-config.json` 和 `web-site/sync-config.json`。见 [查词后台](dictionary-worker/README.md) 和 [加密同步后台](sync-worker/README.md)。

## 免费与内容来源

网页和云服务使用免费方案，没有启用付费计划，但云端有容量和请求额度；达到限制可能暂时无法同步或查词，本地阅读不受影响。每账号一次学习同步约 500KB，保留最多 10 个历史版本。不能承诺免费额度无限或第三方服务永远可用。

内置查词默认开启，可在设置中关闭，词条保留来源和服务条款。英文释义取自必应，部分词条可能没有英文释义；不把读者的正文发往查词后台。应用自带开源组件许可声明，不提供书籍下载。书籍、摘录、词典内容的使用须遵守适用的著作权、许可和 [Microsoft 服务条款](https://www.microsoft.com/servicesagreement/)。程序不授予第三方内容的再发布权。

QQ 邮箱可以由用户手动保存备份附件；本项目未接入其文件空间，没有要求读者提供邮箱密码或登录 Cookie。没有确认到适合本公开网页的官方文件同步接口，因此当前采用已有 Cloudflare 服务。
