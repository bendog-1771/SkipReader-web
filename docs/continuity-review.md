# 上线候选：连续的风与可见的光

色彩沿用深海 #102237、星金 #d7bd97、雾蓝 #adc6cd、云白 #e9f0f3、墨蓝 #233c52。摘录用 Georgia／宋体，控件沿用应用字体；风由方向、轻波和纤维体现，不增添无关场景。句子完整成组，空间留给真实书籍；恒星和音乐圈共享中心；太阳／月亮决定海面的倒影。

```
侧栏： 笔记
       留白
       跃境 → 锚定设置面板
风：   完整句组    → → 风痕与纤维 → →
海：                  日 / 月
                       倒影
星轨：         恒星中心 = 音乐圈中心
```

| Before | After | Why |
| --- | --- | --- |
| 数组引用改变即重播句子 | 引用变化时比较实际内容，保留播放对象 | 切换书籍视图不打断风景 |
| 尺寸／画质通知重置时钟 | DPR 只调画布，窗口改变只排版 | 不在后台重复播放到场动画 |
| 所有摘录至少停留 18 秒 | 8–18 秒按长度分配，成组顺风离开 | 短句有节奏，长文保持可读 |
| 照片天空隐藏程序太阳 | 日月叠加与反射共用同一方向 | 看见光源和对应水面光路 |
| 固定手动光景 | 本地时间自动选择，也保留手动 | 不需要定位或服务端调用 |
| 透视恒星与平面圈视觉偏心 | 星轨独立正交镜头，内侧等距 | 移动、缩放、旋转后仍同心 |
| 三段能量、几乎固定短线 | 32 段频谱、64 根镜像线、快起慢落 | 实际音乐频率和强弱可见 |
| 圆角按钮顶边成为弯折分隔线 | 透明边与 10px 留白 | 和导航统一，不添加装饰 |
| 浅色主题在深星空中低对比 | 深景侧栏底色与浅文字，设置沿用主题 | 入口和书名保持可读 |

不新增动画库或原生工具。32 段频带预计算；频谱缓冲区复用；不按帧更新 React；海面网格、自动降档、阅读降帧、后台停绘保留。日月是当前天空着色器的一部分，没有额外天空层或绘制调用。

488 项本地检查通过，包括原阅读数据、完整备份、并发保存、同步模型／后台、查词、所有场景、手机、连续播放及正式路径离线加载。真实系统音频授权仍由使用者选择，自动测试使用模拟音轨和试听；未测试每一款 GPU，也未创建真实云账号。未修改数据库、同步协议、来源域名或个人书库。
